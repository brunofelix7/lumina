# Project Instructions - Antigravity

The project instructions are shared with Cursor and live in `CLAUDE.md`, included in full below. Follow them exactly as written.

In Antigravity:
- The rules listed in the `CLAUDE.md` table (`.cursor/rules/*.mdc`) are the skills with the same names in `.agents/skills/` (e.g., `android-design-system.mdc` → `.agents/skills/android-design-system/SKILL.md`). The Android standards are always active through `.agents/rules/`.
- `git-commit` and `generate-release-notes` are on-demand skills: use them only when the user asks to commit or to generate release notes.
- `.cursor/templates/` is shared by both tools: it holds the base component templates cataloged in the `android-base-components` skill.
- Wherever the instructions mention Claude or Cursor, they apply to you.
